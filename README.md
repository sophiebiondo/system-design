# system-design
System Analysis &amp; Design at SNHU

What was the problem you were solving in the projects for this course?

We tackled how a program iterates through data in different ways. We had a question to answer in mind: which way is the fastest?


How did you approach the problem? Consider why data structures are important to understand.

Data structures can take run-time and memory availability, which gets expensive quickly. Minimizing the usage of either was a primary goal for this project. 


How did you overcome any roadblocks you encountered while going through the activities or project?

Taking a step back from my program and looking at published works similar to my end goal helped me put my work into perspective.


How has your work on this project expanded your approach to designing software and developing programs?

It has. Oftentimes I would program without run-time or memory usage in mind at all. That is not a realistic way of programming. 


How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

I am confident in my abilities to abstract data, memory usage, and run-time from the user, while delivering results quickly and accurately.
